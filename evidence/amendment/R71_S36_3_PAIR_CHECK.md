the fix set — 478's supersession, §2.2's tag message, §29's hashes, the eleven conversions, or

## 1. RETURNS TO THE FIX SET — §0.1 / §0.2's artifact allocation (= I2/I3)

**Verified live from disk this pass.** `AVAILABILITY_DECLARATION.md` §0.2 still reads:

> "**THIS is what the gate scores.** Criteria 1-4, the reference AUC trio, the shared-label-vector
> licence, and the k-of-N proof count are all statements about Artifact B."

and §0.1 still reads *"Nothing in §6.2's four criteria is evaluated on it"* of Artifact A — while
§0.2, **three paragraphs below its own sentence**, states *"Artifact B stores **no feature
columns**"* and *"No event-to-row timing question can be answered from Artifact B at all."*

**Why it is a counterpart, not an independent stale site.** R66 §2.1 fixes `PREREG.md:478` by
recording in the declaration that criterion 3 is **map-scored** — which, per I1's table, is
precisely what "made the criterion require a **column** and a **cell**". §0.2 says that same
criterion is a statement about an artifact with **no columns**. I1 states the mechanism directly:

> "Both sentences were written when criterion 3 read *'no runtime finding appears on
> `fixture_corrected`'* — a pure silence test… **R9 replaced silence with map-scoring, which made
> the criterion require a column and a cell.** The §0 allocation was never re-derived."

**478 and §0.2 are the same amendment's two faces.** Fixing one and disclosing the other puts a
supersession marker and a contradicting positive description **inside the same file**, both in the
signed object. That is §36.2 exactly.

**Consequence for the cut order, and it reverses my own call.** At B7.3 I said I2/I3 could be cut
without asking. **That was wrong**, and §36.2 is what makes it wrong: I2/I3 *is* the §0 allocation
correction plus R42(i)'s registered definition of `feature pipeline`, and I1 records that the two
"**must land in the same pass, or the criteria allocate to something the registration does not
define**". **I2/I3 cannot be cut while §2.1 is fixed.** If schedule pressure forces a cut, the
coherent pair to drop is **§2.1 + I2/I3 together**, disclosed as one class — not I2/I3 alone.
